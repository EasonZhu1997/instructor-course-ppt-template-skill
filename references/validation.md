## 验证范围

- 原画布尺寸、文本槽完整性、全部内容逐项一致、可编辑文本、页序、内部关系、媒体字节保持。
- 原页几何、背景、图形、文字样式保持；共享主题、母版、布局、表格样式及关系文件完整比对。
- 缺槽、多槽、超长、空白、未知版式、超行、单行大标题过长、坐标/字号/正文/媒体篡改、关系目标丢失均被拒绝。
- 修改共享主题、母版、布局及相关部件会拒绝；旧版未清除元数据的缓存要求重新导入。
- 输出扫描未发现旧课程全文、旧 JSX、备注或自定义属性携带。
- 使用 LibreOffice + Poppler 渲染全部交付页，查看中文、换行与边界。微软雅黑在该渲染环境中通过隔离 Fontconfig 映射到本机 PingFang SC，PPTX 本身仍保留参考字体。此结果不等于已在 PowerPoint/WPS 中验证每个平台的字体度量。

Skill Creator 的 quick_validate 通过。引擎仅依赖 Python 标准库；渲染另需 LibreOffice/Poppler，联系图可选用 Pillow。本记录是此次实测范围，不保证任意长文案或任意字体环境都自动排版正确，后续课程仍须按 SKILL 复查渲染。

## 便携分发验证

独立分发包内置模板、图片和指定源稿。隔离到包含中文与空格的新目录，并从其他工作目录运行：随包模板生成7页/81可编辑文本框并验证成功，随包源稿重新提取后再次生成成功；全7页渲染目视通过。默认DSH执行器dry-run选择随包模板，不依赖原工作区或用户缓存。

安装器首次安装、重复拒绝、备份更新、同源检测、递归目标拒绝与安装后生成通过；备份及staging位于技能搜索根之外，搜索根内不会出现同名旧稿候选。模拟跨文件系统重命名失败时原安装恢复。本轮便携性验证未额外调用模型；模型能力证据仍为上文真实DSH运行。


## 发布示例与颜色边界
