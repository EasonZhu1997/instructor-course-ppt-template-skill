# AIUI 眼镜单绿演示图

在“讲师课程PPT模版Skill”中，按需辅助准备 AIUI 眼镜界面的截图或概念示意。本文提炼自 `aiui-dev` 的 `references/design/monochrome-green.md`，只保留课程配图需要的规则，不替代当前平台文档或目标设备验收。

## 什么时候使用

| 课程画面 | 处理方式 |
| --- | --- |
| 普通课程、课程封面、知识讲解、架构或流程图 | 沿用通用课件配色，不自动改成绿色 |
| AIUI 课程里的普通说明页、手机端界面或开发工具截图 | 保留对应画面的实际设计，不因主题是 AIUI 就全页单绿 |
| 明确展示 Rokid AIUI 单绿眼镜屏幕或 HUD 的区域 | 对该屏幕区域应用下面的单绿规则，课件其他区域保持通用配色 |
| 未说明目标显示设备或实际显示能力 | 先依据课程资料确定目标，不把所有 AIUI 终端都假定为单绿 |

“Rokid AIUI 入门开发”可以使用这条辅助路线；课程名本身不要求每页都有眼镜图。

## 先找真实画面，再决定是否生成

1. 优先使用与本课示例对应、用户有权使用的真机截图或 AIUI 预览截图。保留准确文字和状态，记录来源、界面版本与截图方式。
2. 真机导出的屏幕截图、开发工具预览、透过镜片拍摄的照片应分别标识。前两者不能证明镜片里的实际可读性；后一种还受现场光线和拍摄方式影响。
3. 没有合适截图，且宿主有 `imagegen` 或等效图像生成工具时，可以生成“教学概念示意”。生成后查看真实输出，交付时明确标注其性质，不能称为真机截图或已运行界面。
4. 没有图像生成工具时，提供可复制的提示词、目标文案与构图要求，并说明图片尚未生成。不要伪造图片路径、下载链接、截图或生成成功记录。

不要为配图编造 SDK 函数、设备按键事件、识别结果、在线状态或接口调用成功。示意中的交互只代表教学设想，是否已实现另行验证。

## 单绿画面的具体要求

- 以一种绿色及其明暗层级组织信息，可用 `#40FF5E` 作为配图色彩参考。眼镜显示内容不增加白、红、黄、蓝等语义颜色；错误、成功或离线还要有文字、图标或线型区分。
- 纯黑可以作为演示图片的承托底色。透明眼镜里的黑色区域对应不发光或透明的底层，不能借黑色面板假定现实环境已被遮住；黑底 PNG 也不证明设备具有遮光效果。
- 亮绿留给关键文字和当前焦点。普通正文可参考约 72% 的绿色强度，次要文字约 48%，辅助线约 24% 或更低；重要信息不能只用很暗的细线表示。这些是设计层级参考，不是实测光学亮度。
- 优先留白、细线和少量局部分组。常规结构线可参考 1px，避免粗亮框、持续霓虹光晕和满屏绿色实心卡片；确需选中底色时用约 6–12% 的低强度局部填充。
- 可用 480 × 352 作为本参考的设计画布，保持比例、中心阅读区和清晰边距；横向约 16px、纵向约 12px 的留白是起点。它不是所有设备或 Widget 的固定尺寸声明。
- 一屏突出一个教学要点，缩略到课件实际展示大小后仍能读懂。不要把桌面仪表盘、大段代码或大量细小参数塞进眼镜区域。

## 文字、状态与课堂叙述一起检查

逐字核对标题、中文、标点、数字和状态标签，不能只检查整体“像不像”。生成图若有错字，应修正并重新查看；未修好的图应标为待修，不能以提示词正确代替成图正确。

同一示例的前后状态应保持画布、位置、字号和控件含义一致，只改变本课讲授的内容。明确起始状态、触发动作和结束状态；不能同时出现“待连接”与“已收到响应”，或把同一按钮前后写成无关动作。没有代码或设备记录支持时，使用“交互示意”“演示数据”等标识，不把状态变化说成真实运行结果。

## 当前 PPT 引擎怎样交付这些图

当前 `profile.json` 和 `pptx_engine.py` 只支持文本槽，没有课程图片槽。辅助生成图应作为独立图片文件交付，并给出建议使用页和图注；有真实截图时也遵循同一规则。

不要擅自把图片盖在文字框上，不要偷改 profile、模板背景或固定图形，也不要宣称当前生成命令会自动把图插入 PPT。需要入稿时，先实现明确的图片槽及其比例、裁切和边界校验，或使用用户明确选择的独立编辑流程，再重新检查完整页面。当前 skill 的文本生成成功不等于配图已入稿。

## 示例提示词：Rokid AIUI 入门开发

下例用于没有可用真实截图时的 **Hello AIUI 教学概念示意**。有工具才执行生成；无工具时只交付这段提示词与文字清单。以下文案用于示例，实际课程中应与配套代码和期望状态逐字对应。

```text
为《Rokid AIUI 入门开发》制作一张独立的 Hello AIUI 眼镜界面概念示意图。
只画平面的屏幕内容，不画眼镜外壳、人物、镜片照片或浏览器窗口。
采用 480:352 的画布比例，可等比例输出更高分辨率，不能拉伸。

纯黑承托底色，只用同一种绿色的不同明暗层级，参考 #40FF5E。
这张黑底图用于讲解，不表示透明眼镜能遮住现实背景。
开放布局，中心内容清楚，四周留白；细线、少填充，不做厚重卡片、霓虹光晕或装饰仪表盘。

文字必须精确：
标题：AIUI 入门
主消息：Hello AIUI
状态：初始状态

标题与主消息用清楚的亮绿，状态文字略暗但可读。
只使用以上三处文字，不加入设备参数、网络成功、识别结果、官方认证或真机实测字样。
这是一张教学概念示意，不能伪装成实际设备截图。
```

若课堂要讲“更新问候”这一状态变化，可另出第二张：保持全部布局不动，仅将主消息改为“你好 AIUI”、状态改为“问候已更新”。课件配文说明它是交互示意；真实触发动作及 API 接线需要在应用代码中另行核实。

交付时附上准确文字清单、截图或生成来源、建议图注，例如“Hello AIUI 界面概念示意”。图已生成、图已入稿、应用已运行和眼镜实际可读是不同结果，分别说明已观察到的范围。
